14 — TROUBLESHOOTING

Something not working?

Why am I getting an API error?

Check your API Ninjas key, internet connection, API limits and whether the service is currently available.

Why are there no results?

Try removing the category or keyword filter, searching another year, or allowing the Wikipedia fallback to provide related articles.

Why don't statistics work?

Statistics require Matplotlib. Install it with pip install matplotlib.

Does the application require internet?

Yes. The current version retrieves historical information and date conversions from online services.

15 — FAQ

Frequently asked questions.

What is HisTrophee?

HisTrophee is a desktop historical exploration application built with Python and PyQt5.

Is it free?

The application itself can be distributed as an executable, while external API services may have their own usage limits and policies.

Does it have a database?

The current application does not require a local database. Historical information is retrieved from external services.
